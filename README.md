# Decider AI

AI-powered decision assistant platform built with Angular, Node.js, and LLM integrations.

## Features

- AI decision assistant
- Multi-model support
- OpenRouter integration
- Ollama local AI support
- RSS intelligence collection
- Web scraping engine
- Queue processing
- Real-time analytics

## Tech Stack

Frontend:
- Angular 15
- TailwindCSS

Backend:
- Node.js
- Express
- MongoDB
- Redis
- BullMQ

AI:
- OpenRouter
- Ollama
